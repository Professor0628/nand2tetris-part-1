# Nand2Tetris Part I: From Logic Gates to a Computer

I'm working through Nand2Tetris Part I to understand how a computer works, starting with basic logic gates and moving up to memory, the CPU, machine language, and an assembler.
This repo is just a journal of my learning process :)

## Goals

- Learn how simple logic gates can be combined to build more complex circuits and how it all aligns together to make a working Computer.
- Build and test each part of the computer as I work through the course.
- Keep notes on my design choices, bugs I run into, and what I learn along the way.
- Use what I learn here to get started with processor architecture and RISC-V and more future projects I am currently reading about.
